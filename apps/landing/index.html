Cowork

See what your friends are working on in real time. A tiny desktop companion that shows everyone's activity in a cute overlay.

Download for macOS

Before opening the app — run this once in Terminal

macOS blocks apps from unidentified developers. Run the command below after you drag Cowork to Applications and before you open it. (No Apple dev license here — it's a friendly side project, promise it's not malware 🏠)

sudo xattr -c /Applications/Cowork.app

How it works

1️⃣

Pick a name & avatar

Choose your character from the Animal Crossing-inspired roster.

2️⃣

Share a session code

Create a room and share the code with friends — anyone with the code can join.

3️⃣

See each other's activity

A small overlay on your desktop shows what everyone's doing — coding, browsing, in a meeting, etc.

Privacy

Cowork is designed to be minimal and respectful of your privacy:

  • No keylogging or history. We don't track keystrokes, save browsing history, or capture what you type. We only detect which app is in the foreground (e.g. "VS Code", "Chrome") — never specific URLs or page titles.
  • Only your session can see you. Your activity is streamed in real time only to friends in the same session. Nothing is stored on our servers; when the session ends, it's gone.
  • No account required. You pick a display name and avatar per session. We don't collect email, passwords, or identity.
  • Open source. The code is on GitHub so you can verify what the app does.
