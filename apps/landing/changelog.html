Changelog

v1.3.0 March 14, 2026

  • Fixes to WebSocket event listeners so goal and focus changes sync reliably for everyone (including when someone joins after you've set your goal)
  • UI updates for character control — clearer layout for name, focus, and session goal
  • Activity breakdowns — see time spent per app per friend in the session

v1.2.1 March 14, 2026

  • Session goals — set a goal for the session; visible to friends under your activity
  • Focus status — green (can chat) or red (locked in), toggle in the app

v1.1.0 March 14, 2026

  • Overlay redesign — emoji + app name, goal line, no chat bubbles
  • Cowork window no longer counts as "active app" — previous app stays visible
  • Releases: macOS only

v1.0.0 March 14, 2026

  • Initial release
  • Create or join sessions with a 6-character code
  • Activity detection (coding, browsing, meeting, etc.) with app name
  • Draggable overlay with character avatars
  • macOS support
